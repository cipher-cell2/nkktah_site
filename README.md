# Nuktah website

Arabic-first marketing website for Nuktah, a grade-sheet workflow tool for Algerian teachers.

## Routes
- `/` Arabic landing page (RTL)
- `/en` English landing page (LTR)

## Getting started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The Google Play testing link points to the existing Nuktah closed-testing programme. Pricing is described as credit-based; exact pack prices remain inside the app. No customer testimonials or unverified performance claims are included.
